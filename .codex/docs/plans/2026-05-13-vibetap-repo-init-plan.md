# VibeTap Repo Initialization Plan

**Goal:** Turn this directory into a public GitHub repository with a clean Android app scaffold and core project docs.

## Steps
1. Initialize git and create a safe `.worktrees/`-based workflow.
2. Create a minimal Android/Kotlin project shell with Gradle wrapper, app module, manifest, and placeholder feature packages.
3. Add public-project essentials: README, MIT license, editor config, gitignore.
4. Validate the wrapper/bootstrap as far as the local environment allows.
5. Commit with Lore trailers, create a public GitHub repo, push, and verify.
